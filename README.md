# لوحة تحليل المبيعات العالمية | Global Sales Overview Dashboard

لوحة تحكم تحليلية تفاعلية (Executive Business Intelligence Dashboard) مبنية باستخدام **React 19** و**TypeScript** و**Tailwind CSS v4** و**D3-Geo**، مصممة لتحليل بيانات المبيعات العالمية والأرباح (`Global Superstore 2019–2022`) مع دعم كامل للغة العربية وتنسيق النصوص من اليمين إلى اليسار (**RTL**) وتوافق تام مع شاشات الهواتف الذكية وسطح المكتب.

---

## أبرز المميزات (Key Features)

1. **خريطة الكرة الأرضية التفاعلية ثلاثية الأبعاد (`Orthographic 3D Globe`)**:
   - مبنية باستخدام `d3-geo` وبيانات `world-atlas (countries-110m.json)` الجغرافية الحقيقية.
   - قابلة للسحب والتدوير بالماوس أو اللمس، وتدور تلقائياً نحو أي قارة أو دولة يتم اختيارها من الفلاتر أو جدول الدول.
   - تدرج لوني قرمزي ووردي يعكس حجم المبيعات الفعلي لكل دولة، مع نافذة تلميح (`Tooltip`) فورية عند التمرير.

2. **مؤشرات الأداء الرئيسية الحقيقية (`Headline KPIs`)**:
   - **المبيعات العالمية (`Worldwide Sales`)**: `12.58M$` بمتوسط مبيعات سنوي `3.15M$`.
   - **إجمالي العملاء (`Customers`)**: `795` عميل نشط.
   - **إجمالي الربح (`Gross Profit`)**: `1.46M$ | 11.6%`.
   - **صافي الربح (`Net Profit`)**: `1.1M$ | 8.77%`.
   - جميع الأرقام تستخدم خط `IBM Plex Mono` أحادي العرض (`tabular-nums`) بتباين بصري عالٍ (`kpi-num-crimson` و`kpi-num-white`) لضمان أفضل مقروئية على الخلفية السوداء.

3. **نظام تصفية متعدد الأبعاد (`Multi-Dimensional Filtering`)**:
   - **شريط السنوات (`2019 | 2020 | 2021 | 2022`)**: إمكانية تحديد سنة واحدة أو عدة سنوات لتحديث جميع المؤشرات والرسوم البيانية فورياً.
   - **شجرة القارات الست ومحرك البحث**: تصفية حسب القارات (`أفريقيا، آسيا، أوروبا، أمريكا الشمالية، أوقيانوسيا، أمريكا الجنوبية`) مع إمكانية توسيع كل قارة لاستعراض دولها أو البحث الفوري بالعربية والإنجليزية.

4. **الرسوم البيانية التفاعلية (`Interactive Charts & Tooltips`)**:
   - **المبيعات حسب القطاع (`SegmentDonutChart`)**: مخطط حلقي يوضح توزيع المبيعات بين المستهلكين (`6.48M`)، الشركات (`3.8M`)، والمكاتب المنزلية (`2.3M`) مع إمكانية النقر للتصفية.
   - **المبيعات حسب السنة والربع والفئة (`CategoryTrendChart`)**: مخطط خطي متعدد المسارات يعرض أداء الفئات الثلاث (`الأثاث، مستلزمات مكتبية، التكنولوجيا`) عبر 16 ربعاً سنوياً مع نقاط مضيئة ونافذة تلميح رقمية دقيقة.
   - **الربح حسب المنتج - أعلى 5 (`TopProductsBarChart`)**: مخطط أعمدة يعرض أعلى 5 منتجات ربحية (`Canon imageCLASS 2200`، `Cisco Smart Phone`، `Motorola Smart Phone`، `Hoover Stove`، `Sauder Classic Bookcase`) مع نافذة تلميح تعرض صافي الربح والمبيعات وهامش الربح.

5. **جدول ترتيب الدول المتجاوب (`Responsive Country Ranking`)**:
   - **على سطح المكتب**: جدول مدمج يعرض 35 دولة مع أعلامها المرسومة بدقة (`SVG Flag Badges`)، أشرطة التقدم الحمراء، وقيم المبيعات والنسب المئوية مع إمكانية الفرز التصاعدي والتنازلي.
   - **على الهواتف والشاشات الصغيرة**: يتحول تلقائياً إلى **عرض البطاقات (`Cards View`)** لعرض بيانات كل دولة (الترتيب، العلم، القارة، المبيعات، النسبة، العملاء، وإجمالي/صافي الربح) بوضوح تام.

6. **أدوات التدقيق وتصدير البيانات (`CSV Export & Analytical Modals`)**:
   - أيقونات تحليلية في أعلى اللوحة تتيح استعراض ملخصات التدقيق المالي، مقارنة هوامش الربح، توزيع القارات، وتصدير البيانات المصفاة مباشرة إلى ملف `CSV`.

## هيكل المشروع (Project Structure)

```text
├── index.html                           # نقطة الدخول مع إعدادات العربية (RTL) والخطوط (Cairo, Amiri, IBM Plex Mono)
├── metadata.json                        # بيانات التطبيق الوصفية
├── package.json                         # الحزم والاعتماديات (React 19, D3-Geo, TopoJSON, Tailwind v4)
└── src/
    ├── App.tsx                          # المكون الرئيسي وتخطيط الشبكة وإدارة حالة الفلاتر
    ├── index.css                        # التنسيقات العامة، تباين الأرقام، وتأثيرات التمرير (Hover)
    ├── main.tsx                         # تشغيل تطبيق React
    ├── data/
    │   └── superstoreData.ts            # بيانات المتجر العالمي الحقيقية (2019–2022) ودوال تنسيق الأرقام
    └── components/
        ├── OrthographicGlobe.tsx        # خريطة الكرة الأرضية التفاعلية ثلاثية الأبعاد (D3 Orthographic)
        ├── SegmentDonutChart.tsx        # مخطط المبيعات حسب القطاع (Donut Chart)
        ├── CategoryTrendChart.tsx       # مخطط المبيعات الفصلي حسب الفئة مع التلميحات التفاعلية
        ├── TopProductsBarChart.tsx      # مخطط أعلى 5 منتجات ربحية مع التلميحات التفاعلية
        ├── CountryRankingTable.tsx      # جدول ترتيب الدول (سطح المكتب) وعرض البطاقات (للجوال)
        └── TopHeaderIcons.tsx           # الأيقونات التحليلية الأربع في ترويسة اللوحة
```

## التشغيل والتطوير (Getting Started)

1. **تثبيت الحزم**:
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير**:
   ```bash
   npm run dev
   ```

3. **فحص الأنواع البرمجية وبناء نسخة الإنتاج**:
   ```bash
   npm run lint
   npm run build
   ```
